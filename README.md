# QA Portfolio

This repository contains QA portfolio samples focused on manual testing documentation and quality assurance practices.

## Contents
- Test plan samples
- Test case samples
- Bug report samples

## Purpose
This portfolio showcases structured QA documentation, test design, defect reporting, and validation practices for web applications.

## Repository Structure
- `test-plan/` contains sample test planning documentation
- `test-cases/` contains sample manual test cases
- `bug-reports/` contains sample bug reports
